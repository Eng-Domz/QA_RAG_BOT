# Deep Learning Fundamentals - Comprehensive Lecture

## Introduction to Deep Learning

Deep learning is a subset of machine learning that uses neural networks with multiple layers (hence "deep") to learn hierarchical representations of data. Unlike traditional machine learning algorithms that require manual feature engineering, deep learning models automatically discover features from raw data.

The key breakthrough of deep learning is its ability to learn feature hierarchies automatically. Lower layers learn simple features (like edges in images), while higher layers combine these into more complex concepts (like shapes, objects, or semantic meaning).

## Neural Network Architecture

### The Perceptron - Building Block

A perceptron is the simplest neural network unit, inspired by biological neurons. It consists of:
- Inputs (x1, x2, ..., xn)
- Weights (w1, w2, ..., wn) that determine importance of each input
- A bias term (b) that shifts the activation threshold
- An activation function that determines the output

Mathematical formulation:
output = f(w1*x1 + w2*x2 + ... + wn*xn + b)

Where f is the activation function.

### Multi-Layer Perceptrons (MLP)

A multi-layer perceptron consists of:
1. Input Layer - receives the raw features
2. Hidden Layers - intermediate processing layers (the "deep" part)
3. Output Layer - produces final predictions

Each layer is fully connected to the next, meaning every neuron in one layer connects to every neuron in the next layer.

## Activation Functions

Activation functions introduce non-linearity, enabling neural networks to learn complex patterns.

### Sigmoid Function
- Formula: f(x) = 1 / (1 + e^(-x))
- Output range: (0, 1)
- Historically popular but suffers from vanishing gradient problem
- Still useful for binary classification output layers

### Hyperbolic Tangent (Tanh)
- Formula: f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
- Output range: (-1, 1)
- Zero-centered, better than sigmoid for hidden layers
- Still suffers from vanishing gradients for extreme values

### Rectified Linear Unit (ReLU)
- Formula: f(x) = max(0, x)
- Output range: [0, infinity)
- Most popular activation function for hidden layers
- Advantages: Computationally efficient, avoids vanishing gradient
- Disadvantage: "Dying ReLU" problem where neurons can become inactive

### Leaky ReLU
- Formula: f(x) = max(alpha*x, x) where alpha is small (e.g., 0.01)
- Addresses dying ReLU by allowing small negative values

### Softmax
- Used for multi-class classification output layers
- Converts raw scores (logits) to probabilities that sum to 1
- Formula: f(x_i) = e^(x_i) / sum(e^(x_j)) for all classes j

## Training Neural Networks

### Forward Propagation

Data flows through the network from input to output:
1. Input data is fed into the input layer
2. Each layer computes: z = W*x + b (linear transformation)
3. Activation is applied: a = f(z)
4. Process continues until output layer

### Loss Functions

Loss functions measure how well predictions match actual targets.

#### Mean Squared Error (MSE)
- Used for regression problems
- Formula: L = (1/n) * sum((predicted - actual)^2)
- Penalizes large errors more heavily

#### Cross-Entropy Loss
- Used for classification problems
- Binary cross-entropy: L = -[y*log(p) + (1-y)*log(1-p)]
- Categorical cross-entropy: L = -sum(y_i * log(p_i)) for all classes

#### Sparse Categorical Cross-Entropy
- Used when labels are integers instead of one-hot encoded
- More memory efficient for many classes

### Backpropagation

Backpropagation is the algorithm for computing gradients efficiently:

1. **Forward pass**: Compute predictions and loss
2. **Backward pass**: Compute gradients layer by layer
   - Start from output layer
   - Use chain rule to propagate gradients backward
   - Compute gradient of loss with respect to each weight

3. **Weight update**: Adjust weights using gradients
   - w_new = w_old - learning_rate * gradient

The chain rule is fundamental:
dL/dw = dL/da * da/dz * dz/dw

Where:
- L is the loss
- a is the activation
- z is the pre-activation (linear output)
- w is the weight

### Gradient Descent Optimization

#### Stochastic Gradient Descent (SGD)
- Updates weights using one training example at a time
- Noisy updates but can escape local minima
- Formula: w = w - learning_rate * gradient

#### Mini-batch Gradient Descent
- Compromise between batch and stochastic
- Uses small batches (e.g., 32, 64, 128 examples)
- Most common approach in practice

#### Adam Optimizer
- Adaptive learning rate method
- Combines momentum and RMSprop
- Maintains per-parameter learning rates
- Generally works well with default parameters
- Most popular optimizer for deep learning

#### Momentum
- Accelerates gradient descent by accumulating velocity
- Helps navigate ravines and saddle points
- Reduces oscillations

## Regularization Techniques

Regularization prevents overfitting by constraining the learning process.

### L1 and L2 Regularization

L1 (Lasso):
- Adds sum of absolute weight values to loss
- Encourages sparse weights (many become zero)
- Feature selection effect

L2 (Ridge):
- Adds sum of squared weight values to loss
- Encourages small weights
- More commonly used in neural networks

### Dropout

- Randomly sets neurons to zero during training
- Prevents co-adaptation of neurons
- Forces network to learn redundant representations
- Typical dropout rates: 0.2-0.5
- Disabled during inference (testing)

### Batch Normalization

- Normalizes layer inputs to have zero mean and unit variance
- Applied before activation function
- Benefits:
  - Faster training (allows higher learning rates)
  - Reduces sensitivity to initialization
  - Has slight regularization effect
- Formula: x_normalized = (x - mean) / sqrt(variance + epsilon)
- Learnable parameters: gamma (scale) and beta (shift)

### Early Stopping

- Monitor validation loss during training
- Stop when validation loss stops improving
- Prevents overfitting to training data
- Save model weights at best validation point

## Deep Learning Architectures

### Convolutional Neural Networks (CNNs)

Designed for grid-structured data (images, audio spectrograms).

#### Convolutional Layer
- Applies learnable filters to input
- Each filter detects specific features
- Parameter sharing reduces model size
- Local connectivity captures spatial relationships

Key concepts:
- Kernel/Filter: Small matrix that slides over input
- Stride: Step size when sliding filter
- Padding: Adding borders to preserve spatial dimensions
- Feature Map: Output of applying a filter

#### Pooling Layer
- Reduces spatial dimensions
- Max Pooling: Takes maximum value in each region
- Average Pooling: Takes average value
- Provides translation invariance

#### CNN Architecture Examples
- LeNet-5: Early CNN for digit recognition
- AlexNet: Breakthrough in ImageNet competition (2012)
- VGG: Deep network with small 3x3 filters
- ResNet: Introduced skip connections for very deep networks

### Recurrent Neural Networks (RNNs)

Designed for sequential data (text, time series, speech).

#### Basic RNN
- Hidden state acts as memory
- Same weights applied at each time step
- Formula: h_t = f(W*x_t + U*h_(t-1) + b)

#### Long Short-Term Memory (LSTM)
- Addresses vanishing gradient in basic RNN
- Gating mechanisms control information flow:
  - Input gate: What new information to store
  - Forget gate: What information to discard
  - Output gate: What information to output
- Cell state carries information across long sequences

#### Gated Recurrent Unit (GRU)
- Simplified version of LSTM
- Two gates: reset gate and update gate
- Fewer parameters, faster training
- Often comparable performance to LSTM

#### Bidirectional RNNs
- Process sequence in both directions
- Captures context from past and future
- Useful for tasks like named entity recognition

### Transformers

Revolutionary architecture based on self-attention.

#### Self-Attention Mechanism
- Computes attention between all positions in sequence
- Query (Q), Key (K), Value (V) matrices
- Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) * V
- Captures long-range dependencies efficiently

#### Multi-Head Attention
- Multiple attention mechanisms in parallel
- Each head learns different relationships
- Concatenated and projected

#### Transformer Encoder
- Multi-head self-attention
- Feed-forward network
- Layer normalization
- Skip connections

#### Transformer Decoder
- Masked self-attention (prevents looking ahead)
- Cross-attention to encoder outputs
- Same structure as encoder otherwise

#### Applications
- BERT: Encoder-only for understanding tasks
- GPT: Decoder-only for generation tasks
- T5: Encoder-decoder for sequence-to-sequence

## Advanced Topics

### Transfer Learning

- Use pre-trained models on new tasks
- Fine-tune on domain-specific data
- Dramatically reduces training time and data requirements
- Popular pre-trained models:
  - Vision: ResNet, EfficientNet, ViT
  - Language: BERT, GPT, RoBERTa

### Data Augmentation

Artificially expand training data:
- Images: rotation, flipping, cropping, color jitter
- Text: synonym replacement, back-translation
- Audio: pitch shifting, time stretching

### Hyperparameter Tuning

Key hyperparameters:
- Learning rate: Most critical, typically 0.001-0.1
- Batch size: Affects gradient quality and memory
- Number of layers: Depth of network
- Hidden units: Width of network
- Dropout rate: Regularization strength

Tuning methods:
- Grid search: Exhaustive but expensive
- Random search: More efficient than grid
- Bayesian optimization: Smart search based on past results

### Common Challenges and Solutions

#### Vanishing/Exploding Gradients
- Problem: Gradients become too small or large
- Solutions: Proper initialization, batch norm, skip connections, gradient clipping

#### Overfitting
- Problem: Model memorizes training data
- Solutions: Regularization, dropout, more data, early stopping

#### Underfitting
- Problem: Model too simple
- Solutions: More layers/units, train longer, reduce regularization

#### Local Minima and Saddle Points
- Problem: Optimization gets stuck
- Solutions: Momentum, Adam optimizer, learning rate scheduling

## Practical Deep Learning Workflow

1. **Problem Definition**
   - Define input and output
   - Choose appropriate architecture
   - Select loss function

2. **Data Preparation**
   - Collect and clean data
   - Split into train/validation/test
   - Normalize/standardize features
   - Apply augmentation if needed

3. **Model Building**
   - Define architecture
   - Initialize weights
   - Choose optimizer and learning rate

4. **Training**
   - Forward pass
   - Compute loss
   - Backward pass
   - Update weights
   - Monitor metrics

5. **Evaluation**
   - Test on held-out data
   - Analyze errors
   - Compare to baselines

6. **Deployment**
   - Optimize for inference
   - Monitor performance
   - Plan for updates

## Conclusion

Deep learning has revolutionized machine learning by enabling automatic feature learning from raw data. Key takeaways:

1. Neural networks learn hierarchical representations
2. Backpropagation enables efficient training
