# Sample Document: Introduction to Machine Learning

Machine learning is a subset of artificial intelligence that enables systems to learn and improve from experience without being explicitly programmed. The primary goal of machine learning is to develop algorithms that can access data and use it to learn for themselves.

## Types of Machine Learning

### Supervised Learning
Supervised learning involves training a model on labeled data, where the correct answers are known. Common applications include:
- Classification (e.g., spam detection, image recognition)
- Regression (e.g., price prediction, weather forecasting)

### Unsupervised Learning
Unsupervised learning works with unlabeled data to find hidden patterns or structures. Applications include:
- Clustering (e.g., customer segmentation)
- Dimensionality reduction (e.g., feature extraction)
- Anomaly detection

### Reinforcement Learning
Reinforcement learning involves an agent learning to make decisions by taking actions in an environment to maximize some notion of cumulative reward. Examples include:
- Game playing (chess, Go)
- Robotics control
- Autonomous driving

## Popular Machine Learning Algorithms

1. Linear Regression - Predicts continuous values based on input features
2. Decision Trees - Tree-like models for classification and regression
3. Neural Networks - Inspired by biological neural networks, excellent for complex patterns
4. Support Vector Machines (SVM) - Effective for high-dimensional classification
5. Random Forests - Ensemble method combining multiple decision trees

## Key Concepts

### Overfitting
Overfitting occurs when a model learns the training data too well, including noise and outliers. This results in poor performance on new, unseen data.

### Underfitting
Underfitting happens when a model is too simple to capture the underlying patterns in the data, resulting in poor performance on both training and test data.

### Feature Engineering
Feature engineering is the process of using domain knowledge to extract features from raw data. Good features can significantly improve model performance.

## Applications

Machine learning is used across many industries:
- Healthcare: Disease diagnosis, drug discovery
- Finance: Fraud detection, algorithmic trading
- Retail: Recommendation systems, demand forecasting
- Transportation: Route optimization, self-driving cars
- Natural Language Processing: Translation, chatbots, sentiment analysis
